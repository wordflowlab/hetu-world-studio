# Skill与机器接续

## 接入方式

本包Skills随河图插件注册，外部Codex经同一稳定CLI/MCP即时发现`skills.read`，读取`hetu-world-studio`入口及按需参考。不向Codex安装同名插件，不增加永久客户端工具名，安装生命周期与作品管理连接分开。

## 默认旅程

读取固定正文与设定→建立明确历法与制度假设→核对日期和依赖→在固定情景计算资源→解释不足及影响→交给规划或宿主候选→按新依据继续。

方法入口为[SKILL](../skills/hetu-world-studio/SKILL.md)，[操作地图](../skills/hetu-world-studio/references/operations.md)随清单生成，[流程](../skills/hetu-world-studio/references/workflows.md)描述专业决策。

## 有界发现与内容

先发现当前包摘要与专业Schema，再精确读取必要宿主动作。不全量加载所有插件方法，不用压缩摘要冒充已读原文。大成果使用summary与固定分块完整核验；只读投影不改变写入原输入。

## 恢复与用户决定

未知写入先查原键；同输入明确未落盘才恢复，不换键重复写入。CAS冲突保留输入。Agent执行准备与确定性事务，作者保留采纳、定稿、费用和外发决定。正式正典归宿主；历史与经济判断归作者和外部Agent。本包只计算明确声明的虚构历法及整数资源，不推断真实地理、社会科学结论或自动修改正典。地图及行程投影复用小说图鉴，故事事件偏序复用小说规划。
