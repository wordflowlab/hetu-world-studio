# 工作面与交互设计

## 工作面原则

独立工作面，左上角“返回作品”，宿主顶部和左侧不重复包围插件。页头紧凑，当前工程和修订明确，主要操作是“让AI处理”。高级JSON编辑只作补充，不能替代专业阅读、计算、参考板或媒体播放。

## 视图组织

- 历法与纪年：按对应专业结构阅读，缺少资料时显示具体下一步。
- 制度与规则：按对应专业结构阅读，缺少资料时显示具体下一步。
- 资源推演：按对应专业结构阅读，缺少资料时显示具体下一步。
- 影响与依据：按对应专业结构阅读，缺少资料时显示具体下一步。
- 接续创作：按对应专业结构阅读，缺少资料时显示具体下一步。

## 视觉及可访问性

复用河图Radix色板、静止柔和渐变与半透明表面；正文和输入保持实色。字号12／14／20px，细边框0.5px；无装饰动画。主题、减少透明度与高对比分别仿真；宽窗与窄窗保持完整语义和键盘可达。

## 交互状态

加载保持结构，空状态不虚构内容，失败就地说明；未知写入显示原键回读。刷新不覆盖未保存稿，冲突保持本次输入，显式比较和重建基线后才保存。关闭重开恢复缓冲，停用阻止新调用并保留旧成果。

```mermaid
flowchart TD
    A[打开当前专业工程] --> B{已有成果}
    B -->|无| C[让AI准备或手工新建]
    B -->|有| D[阅读专业视图和固定依据]
    C --> D
    D --> E[表达本次目标或意见]
    E --> F[Agent准备新修订或候选]
    F --> G{固定结果回读}
    G -->|成功| D
    G -->|未知| H[沿原操作查询]
    H --> G
```

## 专业验收重点

虚构月份、闰日、跨年、纪元边界和非法日期; 规则环、传递依赖、假设与作者声明分别报告; 整数资源、负余额、混合单位与安全整数溢出; 修改规则后传递影响明确，旧情景和正典保持; 空世界、部分阅读、多个独立作品、中文引文与CAS恢复。完整实际渲染和尺寸断言见08，不以页面能加载作为完成。

专业视图的背景读取与作者操作使用同一串行调用队列，避免媒体读取与保存争用后端。冲突保留当前输入，明确读新基线后才重新保存；媒体读取失败就地显示错误，不能把读取中误报为无素材。
