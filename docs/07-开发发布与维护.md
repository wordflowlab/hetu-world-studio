# 开发发布与维护

## 技术与开发入口

TypeScript纯领域＋SDK应用层＋React专业视图，受管Node后端；宿主使用Electron、TS插件宿主与Rust Core。包不链接Rust FFI、不内置Agent、LLM渠道、聊天或服务端数据库。

Node.js25，`npm ci`按锁安装；`npm run build`生成校验器和运行包，`npm run check`类型检查，`npm run test:unit`领域单元，机器及界面见根README。

## 测试配置

`acceptance-lock.json`固定正式宿主版本、源码、归档摘要和本包摘要。`scripts/accept-installed.py`下载与核验签名宿主后在隔离目录使用公开CLI/MCP执行业务；不得直写`.hetu`。本机覆盖安装单独验证，不用开发环境变量冒充正式安装。

## 发行与目录

先完成最终包机器、界面和同会话方法验收，再创建不可变v0.1.0 Tag及GitHub Release。发行运行包、归档SHA-256、解压内容SHA-256、源码提交和验收回执。官网登记固定版本及实际工作面；不使用latest URL代替固定发行，不覆盖公开标签或附件。

## 生态与维护

公开JS/TS开发入口及完整机器Schema让第三方按同一合同扩展。专业功能清单由本包维护，宿主只发现包；许可与来源随包分发。缺公共能力先修宿主Owner，不能复制正文库或增加通用旁路。功能改动同步Schema、Skill、用例及08，兼容升级保存旧引用并检测数据丢失。

## 研究与许可

参考lusrelay/dsh-worldbuilding, javalent/calendarium的公开机制，逐个固定克隆提交和实际许可。功能启发不代表复制代码。GPL、定制或未识别许可仅作对照，是否引入源码按具体义务决定。本包与公开SDK、依赖及素材各自保留版权声明。
