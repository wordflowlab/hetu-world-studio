# 架构与技术选型

## 架构原则

宿主保持精炼稳定：作品、固定来源、候选、意见、作者决定及确定性事务归Core；本插件持有世界构建专业结构与算法。领域不依赖Electron、数据库、工具供应商或视图，应用层只依赖公开SDK，视图不直写Core文件。

```mermaid
flowchart TB
    A[作者目标与判断] --> C[外部Codex]
    C --> M[河图稳定CLI MCP]
    M --> P[插件应用用例]
    P --> D[专业纯领域]
    P --> S[公开宿主SDK]
    S --> K[Rust Core]
    K --> R[作品 来源 修订 事务]
    P --> V[React专业工作面]
    V --> A
```

## 技术选型

| 层 | 选择 | 原因 |
| --- | --- | --- |
| 领域 | TypeScript纯函数 | 可直接测试专业正反例，避免协议与算法缠绕 |
| 输入合同 | JSON Schema2020-12、Ajv预编译 | 字段闭合、运行与机器发现一致 |
| 应用 | 公开SDK、ProjectStore | 复用固定引用、CAS和原键恢复 |
| 工作面 | React18、共享Radix语义样式 | 按专业内容渲染，跨系统共享Web层 |
| 构建 | 固定esbuild及TypeScript | 独立运行包、源码与许可可追踪 |
| 分发 | GitHub固定发行＋河图目录 | 包与宿主解耦，逐版本兼容验收 |

Cordis生命周期由宿主负责，本包使用apply／effect／invoke协议，不重新实现调度框架。相同JS/TS技术栈不表示原DSH包直接兼容。

## 专业取舍

正式正典归宿主；历史与经济判断归作者和外部Agent。本包只计算明确声明的虚构历法及整数资源，不推断真实地理、社会科学结论或自动修改正典。地图及行程投影复用小说图鉴，故事事件偏序复用小说规划。

有限输入和预算优先于无界推演；确定性检查报告缺失前提，不伪装语义理解。无第二套作品权限、正文库、模型连接或内部生成循环。

## 风险与验收

格式损失、虚构前提、来源不足、并发修改和平台差异分别取证。实际机器、界面及发行归08；作者认可不能由算法通过代替。
